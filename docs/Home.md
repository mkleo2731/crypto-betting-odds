# Crypto Betting Odds

A comprehensive library for converting and calculating cryptocurrency betting odds across decimal, fractional, American, and implied probability formats.

## Overview

This project provides utilities for working with betting odds in the cryptocurrency gambling space. Whether you are building a sportsbook interface, analyzing market data, or developing arbitrage detection tools, this library handles the math behind odds conversion.

### Key Features

- **Multi-format conversion** — Convert between decimal, fractional, American (moneyline), and Hong Kong odds
- **Implied probability** — Calculate the true probability implied by any odds value
- **Parlay/accumulator math** — Combine multiple selections and compute combined odds and payouts
- **Margin analysis** — Detect and quantify bookmaker overround (vig/juice)
- **Cryptocurrency payouts** — Calculate payouts in BTC, ETH, SOL, and USDT with real-time USD equivalents
